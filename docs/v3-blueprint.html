Autonomous Data Analysis Agent · Version 3 · design locked 2026-10-18

Ask the company's data a question. Get an answer you can trust.

An AI agent that answers a manager's plain-English questions over a company's tables and customer reviews. It shows how it got each answer, asks when a question is unclear, and refuses when the data can't answer. It runs as a deployed, multi-user service.

Key choices

The six decisions that shape everything

Semantic layer, not free SQL

Metrics and data rules defined once. The LLM fills a form; code builds the SQL.

Do the heavy work at load time

Reviews translated, topic-tagged and embedded once a day, not per question.

Hybrid review search

Keyword + meaning search in Postgres (pgvector), filtered by order data.

Router + bounded agent loop

Single agent on LangGraph. Step limit, route-only tools, check after each step.

Read-only, actions need approval

Business data is never changed. Flags and tasks wait for the manager's click.

Built like a real service

API + job queue + workers, login, quotas, tracing, failure handling, evals.

Prevention and budgets

Rate limiter: token bucket per provider, ~85% of limit Bucket empty: wait ≤ 2 s, then fallback, then "busy" Question cap ~30 s; no retry that can't fit Fallback must pass the same evals Tested with a fake failing adapter

Memory, caching, observability

What's remembered, reused and watched

Short-term memory

Last ~5 turns: question, structured request, one-line summary, result ID.

Long-term memory

Only preferences the manager asks to save, as fixed keys. Stated in answers.

Caching

Result cache by structured request; exact-question cache keyed with preferences. Cleared at publish.
